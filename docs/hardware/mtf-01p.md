The [MicoAir MTF-01P](https://micoair.com/optical_range_sensor_mtf-01p/) is a compact 2-in-1 optical-flow range sensor designed for drones and autonomous aircraft. It combines horizontal motion sensing with precise altitude/distance measurement, making it particularly useful for indoor flight, low-altitude navigation, and position/altitude assistance where GPS may be unavailable or unreliable. The module supports ArduPilot, PX4, INAV, and FMT.

In this project, MTF-01P serves as a kinetic sensor specifying the distance and relative velocity with respect to the ground. It communicates with the flight controller via the UART5 port using the MAVLink protocol. Detailed setup process will be shown in the sensor section.
